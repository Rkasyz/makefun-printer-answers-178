Answers": the office printer's comeback to the paper jams, the cryptic
error codes and the thumps — in the machine's own voice: weary, literal,
faintly passive-aggressive.

## The entry (170 characters)

> Error 0xJAM: I have fed 47,312 sheets without complaint. This one I kept — as a souvenir, and as evidence. Please remove it gently; I am a printer, not a vending machine.

## How to run

`main.py` (Python 3, standard library only) writes the line to
`entry.txt` in the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is deterministic: no time, no randomness, no network. It
writes the exact same bytes on every run.
